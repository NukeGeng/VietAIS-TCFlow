# FullStackHero baseline notice

The backend foundation in this repository is derived from
`fullstackhero/dotnet-starter-kit` release `2.0.4-rc`, commit
`8e762f081c98cc1d75d6baaab0c67c516b0313bc`.

The upstream license is preserved in `LICENSE` in this directory. The imported
source has been adapted for VietAIS TCFlow, including namespace changes,
removal of the upstream Blazor UI, Aspire PostgreSQL and Redis resources,
Marten registration, secret handling, dependency security updates, and test
coverage.
